ESP32S3CAM 嵌入式视觉系统 基础题 使用 AI 完成题目说明

一 这份说明怎么用

这份说明面向第一次接触 ESP32、Arduino 或网页聊天 AI 的新生。你可以让 AI 帮你安装软件、配置环境、理解题目、编写代码、修改代码和排查错误。你不需要先学会使用编码代理，使用能够上传文件或粘贴文字的网页聊天 AI 即可。

开始前准备两个文件：

1. 题目文件“2026招新H题_ESP32-S3_CAM嵌入式视觉系统.pdf”。
2. 本文件夹中的“02_基础题_底座程序说明_提供给网页AI.txt”。

每次新建 AI 对话时，先上传题目文件和底座程序说明。网页 AI 通常看不到你电脑中的工程，不能只告诉它“我在做 ESP32 招新题”，否则它很可能按别的开发板、别的程序或别的接口回答。

这里的“串口”是电脑与开发板通信的 USB 设备名称。Windows 常见 `COM5`；macOS 常见 `/dev/cu.usbmodem1101` 或 `/dev/cu.usbserial-xxxx`。后文统一称“串口”。

二 首先发给 AI 的固定要求

上传上述两个文件后，把下面这段话发给 AI：

【复制给 AI】
你需要帮助我实际完成“ESP32S3CAM 嵌入式视觉系统”基础题，包括安装软件、配置环境、编写代码、编译、烧录和根据运行结果修改代码。题目要求以我上传的最终 H 题 PDF 为准，工程结构和接口以我上传的底座程序说明为准。

禁止凭经验猜测我的电脑环境、开发板型号、摄像头引脚、软件版本、文件内容、函数声明或报错原因。如果继续回答所需的信息还不完整，请先向我提出具体问题，等我回答或上传文件后再给结论。需要查看某个文件时，请直接告诉我准确的文件路径以及需要上传整个文件还是其中哪一段。

开始操作前先确认我的操作系统和电脑 CPU：Windows / macOS；Apple Silicon / Intel / 不清楚。macOS 用户要按芯片架构选择 Arduino IDE，再给对应步骤。

你可以给我可直接使用的代码，但必须说明代码属于哪个文件、替换哪个函数或插入哪个位置。不要修改题目和底座说明没有授权我修改的底座文件。如果你准备使用底座说明中没有列出的函数、库、类或字段，必须先让我提供相应头文件或官方资料，确认存在后再写代码。

我的编程基础较少。请一次只让我完成一小步，每一步说明我要点击什么、输入什么、应该看到什么。完成当前步骤后先等我反馈，再继续下一步。
【复制结束】

如果 AI 没有先询问你的操作系统、电脑 CPU、开发板和当前进度，可以再发：

【复制给 AI】
请先不要给代码。先询问我的操作系统和版本、电脑 CPU（Apple Silicon / Intel / 不清楚）、开发板和当前进度，以及完成当前步骤必须知道的其他信息，不要自行补全缺失信息。
【复制结束】

三 准备硬件信息

题目要求使用带摄像头的 ESP32-S3 CAM 开发板，Flash 至少 4 MB，PSRAM 至少 8 MB。购买或拿到开发板后，拍清楚开发板正反面、商品型号和摄像头排线位置。不要让 AI 只根据外观模糊猜型号。

把下面的信息按实际情况填写后发给 AI：

【复制给 AI】
我的操作系统是：[Windows / macOS，以及版本]
电脑 CPU 是：[Apple Silicon / Intel / 不清楚；Windows 用户也可写不清楚]
开发板商品名称或型号是：[填写完整名称]
Flash 容量是：[填写；不知道就写不知道]
PSRAM 容量是：[填写；不知道就写不知道]
摄像头型号是：[填写；不知道就写不知道]
开发板连接电脑后是否出现新的串口：[是／否／不知道]
我附上了开发板正反面和商品页面截图。

请先检查这些信息是否足够判断它能否使用当前底座。信息不足时告诉我还要拍哪里、查看哪里或向卖家确认什么，不要猜引脚。
【复制结束】

如果 AI 判断硬件信息与工程当前选择的摄像头型号不一致，不要马上照抄它给出的引脚。先让 AI 指出判断依据，并要求它查看工程中的 board_config.h、camera_pins.h 和你的开发板资料。

四 安装 Arduino 开发环境

基础题推荐使用 Arduino IDE 2.x，并安装“esp32 by Espressif Systems 3.3.7”。工程提供 Windows 和 macOS 固定配置的一键编译、烧录工具。macOS 用户只需先安装 Arduino IDE 2.x；不需要安装 Homebrew、Python 或独立 Arduino CLI。

Windows：安装 Windows 版 Arduino IDE 2.x。

macOS：在 Apple 菜单 → 关于本机查看“芯片”或“处理器”。显示 Apple M 系列时下载 Apple Silicon 版 Arduino IDE；显示 Intel 时下载 Intel 版。Apple Silicon 用户优先使用原生 Apple Silicon 版本。

让 AI 陪你安装时，使用下面的提问：

【复制给 AI】
我要在这台电脑上安装基础题所需的 Arduino 环境。我的操作系统和版本是：[填写]，电脑 CPU 是：[Apple Silicon / Intel / 不清楚]。我目前已经安装的软件有：[填写，没有就写没有]。

请根据题目要求指导我安装 Arduino IDE 2.x 和 esp32 by Espressif Systems 3.3.7。先按操作系统和 CPU 确认正确的 IDE 架构。一次只给一个步骤，说明操作位置和该步骤完成后应看到的界面。不要假定我已经配置过开发板网址、驱动或串口。如果同一软件有多个版本或多个下载入口，先向我确认再继续。
【复制结束】

安装过程中遇到任何异常时，先截取完整窗口，不要只截最后一行。把截图和以下信息一起发给 AI：

- 操作系统和版本；电脑 CPU（Apple Silicon / Intel / 不清楚）。

- 当前进行到哪一步。
- 点击或输入了什么。
- 预期看到什么。
- 实际看到什么。
- 完整报错文字。
- Arduino IDE 版本和已安装的 ESP32 Core 版本。

要求 AI 根据这些信息继续提问。不要接受“可能是驱动问题”“可能是网络问题”这类没有说明验证方法的猜测。

五 打开工程并先运行原始底座

基础题工程目录是：

project/CameraWebServer

主要编辑文件是：

project/CameraWebServer/CameraWebServer.ino

在让 AI 写题目代码前，先确认原始底座能否编译、烧录和显示画面。这样出现问题时，AI 才能分清是环境问题、硬件问题还是后来修改的代码问题。

向 AI 发送：

【复制给 AI】
我的操作系统是：[Windows / macOS，以及版本]；电脑 CPU 是：[Apple Silicon / Intel / 不清楚]。请按我的平台指导我在不修改代码的情况下运行基础题原始底座。工程位于 project/CameraWebServer。

Windows 工具：
- 一键编译（固定DIO40）.cmd
- 一键烧录（固定DIO40）.cmd

macOS 工具：
- 一键编译（macOS固定DIO40）.command
- 一键烧录（macOS固定DIO40）.command

macOS 用户只运行 `.command` 工具，不运行 Windows 的 `.cmd`、`.ps1` 或 `.exe`。

推荐使用 Windows / macOS 通用的浏览器 Viewer：启动后连接 esp32s3cam-xxxx，密码 11223344，然后访问 http://192.168.4.1/。Windows 用户如有特殊需要，也可以继续使用 CameraStreamViewer.exe；不要同时打开浏览器 Viewer 和 exe。

请先询问我当前 Arduino IDE、ESP32 Core、串口和开发板情况，然后一次指导一个操作。每一步告诉我应该打开哪个文件、运行哪个工具，以及完成后要把什么日志或截图发给你。不要根据一句“失败了”猜原因。
【复制结束】

推荐使用浏览器 Viewer。ESP32-S3 启动后：

1. 电脑连接 `esp32s3cam-xxxx`；
2. 输入密码 `11223344`；
3. 浏览器访问 `http://192.168.4.1/`。

Windows 用户如需兼容原来的 Viewer，也可以使用 `tools/CameraStreamViewer.exe`。exe 和浏览器 Viewer 都会占用视频流，请只开一个。

连接 `esp32s3cam-xxxx` 后，Windows 或 macOS 都可能提示“无 Internet”“没有互联网连接”或“此网络无法访问互联网”，这是正常现象。ESP32-S3 创建的是电脑与开发板直接通信的本地 Wi-Fi 热点，本来就不提供互联网。请确认当前 Wi-Fi 名称仍为 `esp32s3cam-xxxx`。

六 让 AI 编写基础题代码

确认底座原始画面可用后，再让 AI 写代码。将当前 CameraWebServer.ino 也上传给 AI，防止文件已经被你或别人修改而与说明不一致。

使用下面的提问：

【复制给 AI】
现在请帮助我完成最终 H 题 PDF 中的基础部分。我已经上传题目、底座程序说明和当前 CameraWebServer.ino。

请先逐条复述基础部分必须达到的效果，并检查现有信息是否足够。缺少目标实物颜色、开发板情况、当前代码或其他必要信息时，先向我提问，不要自行假定。

信息确认后，请给出适用于当前工程的代码，并明确说明：
1. 修改哪个文件；
2. 替换哪个函数或插入哪个位置；
3. 我是否需要保留原有 setup()、loop() 和底座调用；
4. 编译前还要检查什么；
5. 怎样用实际色块观察代码是否达到题目要求。

代码必须使用底座文件中真实存在的结构和接口。如果你需要底座说明中没有提供的内容，请先让我上传相应文件，不得自行创造接口。
【复制结束】

AI 给出代码后，先检查它有没有写清楚文件名和替换位置。若只给出零散片段而你不知道放在哪里，可以发：

【复制给 AI】
我不会使用编码代理，也不确定这些片段应放在哪里。请根据我上传的当前 CameraWebServer.ino，给出完整的可替换函数，并清楚标出函数开始和结束位置。不要省略原文件中必须保留的底座调用。
【复制结束】

七 编译错误时怎么让 AI 修改

编译失败时，不要只发送最后一行。复制从第一次出现 error 的位置开始，到命令结束为止的文字；同时上传修改后的 CameraWebServer.ino。

【复制给 AI】
我的操作系统是：[Windows / macOS，以及版本]；电脑 CPU 是：[Apple Silicon / Intel / 不清楚]。
Arduino IDE 版本是：[填写]；ESP32 Core 版本是：[填写]。
这是我按照你上一次回复修改后的完整 CameraWebServer.ino，以及本次编译输出。请先从日志中找到第一个实际错误，不要被后续连带错误带偏。

请检查错误是否来自文件内容、函数声明、变量作用域、类型、缺少的头文件或并不存在的接口。如果现有日志无法判断，请先告诉我还要提供哪个文件或哪一段完整输出。确认原因后，再给出新的完整可替换代码和准确替换位置。
【复制结束】

如果 AI 写了工程中从未出现过的函数名，让它停止修改并重新核对“02_基础题_底座程序说明_提供给网页AI.txt”和当前源文件。

八 烧录和串口问题怎么问

烧录失败时提供：

- 操作系统和版本、电脑 CPU（Apple Silicon / Intel / 不清楚）。
- Arduino IDE 版本和 ESP32 Core 版本。
- 当前串口（Windows 示例 COM5；macOS 示例 /dev/cu.usbmodem1101）。
- Windows：提供“设备管理器”中串口相关截图。macOS：优先提供 Arduino IDE → Tools → Port 中连接前后的变化；如果看不到串口，也可提供 `ls /dev/cu.*` 输出。若仍无法判断硬件，请提供开发板正反面照片和商品型号。
- 一键烧录窗口的完整输出。
- 开发板是否有 BOOT、RESET 等按键以及你实际按过什么。
- USB 线连接的位置和开发板指示灯现象。

向 AI 说明“请先根据这些事实判断还缺什么信息，不要直接假定是数据线、驱动或按键问题”。

串口不断重启、摄像头初始化失败或没有热点时，提供操作系统和 CPU、从复位开始的完整 115200 串口日志、开发板型号和摄像头照片，并让 AI 先核对硬件信息与 board_config.h、camera_pins.h 的关系。

九 画面和识别效果不对时怎么问

浏览器 Viewer 能显示画面但效果不符合题目时，每次只描述一个最明显的问题。上传：

- 当前完整 CameraWebServer.ino。
- 浏览器 Viewer 的完整截图。
- 色块实物照片。
- 色块颜色、大小、距离和大致位置。
- 目标移动、停止或移出画面后分别发生了什么。
- AI 上一次让你修改了什么。

可以使用以下提问：

【复制给 AI】
我的操作系统是：[Windows / macOS，以及版本]；电脑 CPU 是：[Apple Silicon / Intel / 不清楚]。程序已经能够运行，但目前最明显的问题是：[填写一种现象]。我附上当前代码、浏览器 Viewer 画面截图和色块照片。

请先对照最终 H 题 PDF 判断是哪一项没有达到要求。如果截图和描述不足，请先问我需要改变色块位置、距离、光照或移动方式中的哪一个，并等待结果。确认现象后，再修改当前代码。请给出完整可替换函数和替换位置，不要同时改动与这个现象无关的部分。
【复制结束】

常见现象包括：看不到画面、画面颜色异常、始终找不到色块、把背景当成色块、坐标方向不对、目标移走后旧结果仍在、标记位置不对、目标静止但结果明显跳动、修改后画面卡住或设备重启。这里只列出现象，不代表原因；原因必须由 AI 根据你的代码、日志和图片判断。

十 完成前让 AI 对照题目检查

基本效果完成后，把最终 CameraWebServer.ino、不同情况下的画面截图和最终 H 题 PDF 再次发给 AI：

【复制给 AI】
我的操作系统是：[Windows / macOS，以及版本]；电脑 CPU 是：[Apple Silicon / Intel / 不清楚]。
请只依据最终 H 题 PDF 的基础部分逐项检查我的最终代码和运行截图。指出尚未达到或无法从现有材料确认的要求。无法确认时先告诉我还需要做什么现场观察或提供什么截图，不要假定已经通过。

随后请用适合新生的语言解释最终代码中与图像格式、目标位置、坐标偏差和画面标记有关的主要流程，帮助我准备现场说明。
【复制结束】

AI 的回答可能出错。凡是与题目文字冲突的内容，以最终 H 题 PDF 为准；凡是与实际函数声明冲突的代码，以当前工程源文件为准。发现冲突时，把冲突的两段原文一起发给 AI，要求它先确认再重写。
